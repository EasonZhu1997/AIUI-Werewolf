# 本机预览

眼镜页面使用官方 AIX CLI 预览。先按 [README](../README.md)安装依赖并准备 `.env`，再生成连接本机服务的预览包：

```sh
node tools/configure.mjs ws://127.0.0.1:8790/werewolf/ws
npm run build
npm run preview
```

CLI 会打印随机端口的地址，例如 `http://127.0.0.1:52594/`。在另一个终端，用当次打印的 Origin 启动游戏服务：

```sh
DEEPSEEK_ENV_FILE=.env WEREWOLF_PREVIEW_ORIGINS=http://127.0.0.1:52594 npm start
```

Origin 不含末尾斜杠。若 8790 端口的服务已运行，先停止再用上述命令启动；重启会清空临时牌局。显式预览例外仅接受本机 HTTP Origin，正式公网服务不需要开启。

打开 [网页客户端](http://127.0.0.1:8790/werewolf/)，在网页和眼镜预览中进入同一房间，可检查席位同步、阶段变化与按钮操作。任意在线真人都能开局。预览适合检查 480 × 352 页面、路由和通信，不具备真实眼镜的麦克风、扬声器或姿态硬件；声音不可用时会显示提示并跳过本机播放。

本地包带 `LOCAL-ONLY` 标记。其中的 `127.0.0.1` 指运行包的设备自身，不能直接让实体眼镜连接电脑。实体眼镜应使用可访问的 WSS 服务重新配置和打包；USB 本机联调则需自行建立正确的端口转发。完整设备检查见[测试说明](TESTING.md)。
