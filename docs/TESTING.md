# 测试与验证

测试分为规则与协议、模型接入、界面交互和真实设备。模拟客户端或音频宿主通过，不等于眼镜麦克风与扬声器已通过实测。

## 自动化测试

安装依赖后，在工程根目录运行：

```sh
npm test
python3 -m unittest discover -s test -p 'deploy*_test.py' -v
```

Node 测试覆盖游戏规则、房间隔离、六席与单人开局、私密视图、过期行动、重连、等待聊天、语音生命周期、管理鉴权与监控。部署测试使用临时目录和模拟系统命令。两者均不调用真实 DeepSeek，也不连接生产服务器；测试数量以当前输出为准。

0.1.4 的首夜回归覆盖不同真人身份与座位、首夜查验和药水保留、第一天正常投票、第二夜恢复袭击与用药、多人首夜正常及断线不改规则。狼队夜间最高票平票使用可注入随机源验证，确保目标不固定偏向低座位号。

发言性格测试覆盖六席人设与隐藏身份独立、恶意昵称和聊天数据不进入系统人设，以及夜间行动、投票指令和合法选项不受人设影响。

## 真实模型联调

先按 [README](../README.md)准备 `.env`。选择需要验证的场景运行：

```sh
DEEPSEEK_ENV_FILE=.env node tools/smoke-live.mjs 1
DEEPSEEK_ENV_FILE=.env node tools/smoke-live.mjs 2
```

参数是模拟真人数，其余席位由真实 AI 补齐。脚本启动临时本机服务，发送模拟真人行动与播放确认，并等待胜负结果。它会产生真实模型用量，输出报告到 `verification/`，用于验证模型与牌局流程，不验证实际发声。

测试已部署服务时，可在自己的 WSS 地址上执行：

```sh
node tools/smoke-public.mjs \
  --url wss://your-domain.example/werewolf/ws \
  --humans 2 \
  --output verification/public-game-2human.json
```

此脚本使用线上服务的模型额度，不读取本机密钥，也不启动本机游戏服务。默认限制为三分钟、四轮；真人输入与播放确认仍由脚本模拟。报告可能包含测试发言，分享前应检查内容。

## 房间与完整牌局

使用不同浏览器配置文件或两台设备。同一浏览器配置文件内的两个标签页会恢复同一个座位。

1. 创建房间，检查分配四位号码；让另一客户端通过房号或等待大厅加入。单人可开局，后来加入的真人也可开局。
2. 等待区给 AI 发一条确认后的文字，检查两端收到同一回复，AI 伙伴不占座位。开局时，未完成的聊天、等待语音和草稿应取消。
3. 单人开局后检查五个 AI 补位；双人开局则补四个。每位真人只收到自己的身份和私密线索。
4. 按提示完成夜晚行动、轮流发言和投票，检查阶段提示、旁观状态、胜负和最终身份公开。任何在线真人都可在结算后返回等待区。
5. 检查不同房间看不到彼此的席位与发言，公共大厅与 `0000` 分开。第七位玩家、开局后的新玩家和过期行动应被拒绝。
6. 检查夜间公共提示不暴露其他角色的行动顺序；网页动画不遮挡操作，启用减少动态效果后停止持续动画。

单人开局时，首夜应明确显示「单人练习 · 首夜平安」，仅预言家能查验，狼人和女巫无行动选项；天亮时六席存活、药水未消耗，真人可以发言。第一天投票仍可正常放逐真人，第二夜可以正常袭击与用药。多人开局首夜正常；中途断线或重连不应切换规则，返回等待区后重新开局才按当时真人数重新确定。

## 语音与中断

1. 主动点击试听，确认设备实际发声。进入页面或加入房间本身不应自动开启麦克风。
2. 在等待聊天或自己的发言回合主动识别，检查只生成草稿，确认后才同步给其他玩家和 AI。
3. 在另一设备实际听到确认文字和 AI 发言的朗读；仅看到“朗读完成”不足以证明声音可听。
4. 拒绝麦克风权限，检查提示及网页文字输入备用方式；不支持朗读时仍能阅读完整发言并继续游戏。
5. 识别或朗读中隐藏页面、离开房间、静音或切换阶段，检查麦克风与播放停止；迟到回调不得自动发送或覆盖下一回合草稿。

本项目的语音是「识别 → 确认文字 → 各端 TTS」，不转发原始音频。浏览器与 AIUI 的识别能力、权限和声音需分别验证。

## 断线与管理后台

1. 牌局中断开一端，用原客户端恢复相同房间，检查座位和身份不变；同一恢复凭证的新连接应替换旧连接。
2. 全员离线后再连接，检查计时暂停恢复；仍有人在线时，断线玩家按超时规则处理。
3. 服务重启后用旧座位记录加入，检查失效提示与重新入座流程。
4. 按[后台说明](ADMIN.md)启用管理，检查未登录不能读取状态，登录后能看到创建、加入、阶段切换与离开；退出后旧会话失效。
5. 管理页面不应出现隐藏身份、私密线索、夜间目标、聊天正文、密钥或座位恢复凭证。

## AIX 与眼镜

按 [README](../README.md)配置实际 WSS、构建并导出。`dist/validation.json` 记录当前包的版本、UUID、SHA-256 与大小；此报告不证明安装或设备运行。

实体眼镜需要检查：

- Studio 导入 `agent/` 根目录后，页面可以正常打开，文字和操作完整可见。
- 主动语音识别获得权限，草稿正确，确认后同步；实际听到中文朗读，并能停止。
- 房号页校准后左右摆头可改变数字，回正后才能再次触发；反转、重新校准和按键备用操作有效。
- 夜晚行动、投票、发言确认与长文字翻页可以通过镜腿完成。
- 眼镜与浏览器经同一 WSS 房间完成双方发言和投票，隐藏页面后能恢复座位。

当前真实眼镜麦克风、出声与摆头操作仍待验收。记录设备型号、运行时、版本、网络与实际结果，再判断具体设备的兼容性。发现问题请按[贡献指南](../CONTRIBUTING.md)提供复现信息。
